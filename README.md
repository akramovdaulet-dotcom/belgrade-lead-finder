# Belgrade Lead Finder

Бесплатный статический MVP для поиска заведений в Белграде, которым потенциально можно предложить сайт или веб-приложение.

## Возможности
- Поиск по району или по разрешённой геолокации браузера.
- Категории: кафе, рестораны, fast food, барбершопы, салоны.
- Фильтр по отсутствующему website-тегу в OpenStreetMap.
- Карта, телефон (если внесён), маршрут, ссылка на источник, CSV-экспорт.
- Работает на iPhone в Safari после публикации через HTTPS.
- Не требует API-ключа, базы данных или платного хостинга.

## Публикация на GitHub Pages с iPhone
1. Создай новый публичный репозиторий GitHub, например `belgrade-lead-finder`.
2. Загрузи в корень репозитория `index.html`, `styles.css`, `app.js`.
3. Открой Settings → Pages.
4. Выбери Deploy from a branch → `main` → `/ (root)` → Save.
5. Подожди публикации и открой показанный GitHub Pages URL в Safari.

## Важные ограничения
- Данные берутся из OpenStreetMap. Если сайт не указан в OSM, это не доказывает, что сайта у бизнеса нет. Проверяй через Google/карточку заведения.
- В OSM может отсутствовать телефон, сайт или адрес.
- Публичные Overpass/Nominatim сервисы имеют лимиты. Не запускай массовые повторяющиеся запросы и не автоматизируй сбор без проверки их политик.
- Геолокация запрашивается только после нажатия кнопки. Координаты не сохраняются этим приложением и передаются сервису Overpass для выполнения поиска.
- CSV экспортируй и храни аккуратно. Используй данные для уместного B2B-обращения, не рассылай спам и соблюдай просьбы больше не связываться.
- Это лидогенератор, а не подтверждённый каталог клиентов.
- В проекте нет автосообщений, обхода CAPTCHA, сбора приватных данных или проверки уязвимостей сайтов.
- Карта и геокодер используют внешние сервисы; если они недоступны, поиск может не сработать.
